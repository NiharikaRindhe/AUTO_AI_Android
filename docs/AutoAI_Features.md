# AutoAI Features

## Core assistant
1. Always-on background assistant
2. Wake by orb tap or steering button
3. Wake word "Hey Vega"
4. Voice detection (end of speech)
5. Live speech-to-text with captions
6. Contact names boosted in speech-to-text
7. Spoken replies
8. Male / female voice
9. Music lowers while Vega listens or talks
10. Interrupt Vega by tapping the orb
11. Follow-up listening after a question
12. Welcome and goodbye

## Brain
1. Simple commands answered without the LLM
2. Qwen LLM on the device
3. Quick Qwen fine-tune
4. Compound commands
5. Contact name matching (Indian spellings, Mom / Dad)
6. Spoken confirmations
7. Small talk

## Apps and system
1. Open apps
2. Close apps
3. Home screen
4. Volume control
5. Open settings pages
6. Brightness

## Media
1. YouTube search
2. Spotify search and play
3. Pause / play / next / previous
4. Pick a result by number
5. What's playing
6. YouTube audio only while driving

## Navigation
1. Navigate to a place
2. Home / office
3. Nearby search
4. Pick a nearby result
5. Stop navigation

## Calls
1. Call a contact
2. Dial a number
3. Answer / reject / end call
4. Incoming call announcement
5. Choose between matching contacts

## Messages
1. SMS draft → review → edit → send
2. Read the draft back
3. Incoming message announcements
4. Privacy ON / OFF / ASK
5. WhatsApp basics
6. OTP and bank messages never read aloud

## Car (simulated)
1. Windows
2. AC on / off and temperature
3. Fan speed
4. Ambient light
5. Car panel on screen


## Safety
1. No message sent without "send" or "yes"
2. Every action logged
